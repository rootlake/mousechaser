🎮 Mouse Chaser Game

An Interactive Browser-Based Survival Game

Project Overview

Mouse Chaser is a simple yet engaging browser-based game built entirely with vanilla web technologies. The game challenges players to keep their mouse cursor away from a pursuing chaser for as long as possible. As time progresses, the chaser's speed increases, creating an escalating difficulty curve that makes each playthrough more intense.

Key Features

🎯 Real-Time Tracking

The chaser follows your mouse cursor position with smooth, responsive movement.

⚡ Progressive Difficulty

Speed multiplier increases every 10 seconds, making the game progressively challenging.

⏱️ Live Timer

Real-time display of survival time with precision to hundredths of a second.

📊 Speed Indicator

Visual feedback showing current speed multiplier for transparency.

💥 Collision Detection

Accurate distance-based collision detection using Euclidean distance calculations.

🔄 Restart Functionality

Seamless game restart without page reload for continuous gameplay.

Core Algorithms

Movement Calculation:

// Vector-based movement algorithm const dx = mouseX - chaserX; const dy = mouseY - chaserY; const distance = Math.sqrt(dx * dx + dy * dy); const speed = baseSpeed * speedMultiplier; chaserX += (dx / distance) * speed; chaserY += (dy / distance) * speed;

Collision Detection:

// Euclidean distance calculation const distance = Math.sqrt( Math.pow(chaserX - cursorX, 2) + Math.pow(chaserY - cursorY, 2) ); return distance < collisionThreshold;

Speed Progression:

// Time-based speed multiplier speedMultiplier = 1.0 + (elapsedTime / 10);

How to Play

  1. Open the game in a web browser
  2. Move your mouse cursor around the screen
  3. Avoid the red chaser circle
  4. Watch your survival time increase
  5. Monitor the speed multiplier as difficulty increases
  6. When caught, view your final time and restart to try again!
